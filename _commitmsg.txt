M17: something proposes, the verifier judges

tools/policy_loop.py measures a baseline, proposes five policies, and keeps one only
when the full verifier passes, the region hash is identical, and the cost is strictly
lower. Three accepted (296/104, 292/292, 290/162 against a baseline of 352/352) and two
refused: one identical to the baseline, one a corrupted table that fell back to defaults.
Repeatable across runs; decisions recorded append-only outside the kernel.

Two harness defects surfaced only because something automated called the tools in a loop:
run_vm.bat's watchdog read "QEMU not started yet" as "QEMU already exited", so the batch
returned while the guest was still writing and any caller reading the log immediately got
a truncated one; and the loop then read the serial file mid-flush. Both fixed.
